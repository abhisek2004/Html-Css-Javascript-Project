# Environment Requirements

## System Requirements

* **OS:** Windows, macOS, or Linux
* **Code Editor:** VS Code (recommended)
* **Browser:** Google Chrome or Mozilla Firefox
* **Preview:** VS Code Live Server extension (recommended)

## Project Requirements

This project is built using **vanilla HTML, CSS, and JavaScript**.

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, responsiveness, and animations
* **JavaScript (ES6+)** — Dynamic functionality and interactions
* **No frameworks required**
* **No npm packages or external dependencies required**
* **No build tools required**

## Recommended VS Code Setup

Install the following VS Code extension:

* **Live Server** — for running the project locally with automatic browser refresh

## Running the Project

1. Clone or download the repository.
2. Open the project folder in **VS Code**.
3. Make sure the HTML, CSS, and JavaScript files are present in the project structure.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. The project will open in your default browser.
